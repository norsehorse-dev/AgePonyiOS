AgePony 5.0.1 brings keys that live in hardware, keys you can move to another phone or put on paper, and every fix from a full security audit.

New
- Hardware keys: make a decryption key inside this iPhone's Secure Enclave, published as an age 1.3 recipient. A quantum-safe form adds ML-KEM-768.
- Decrypt with a hardware security key over NFC.
- Encrypt to age 1.3 tag recipients.
- Move keys to another phone: scan a code and your keys go straight across the same Wi-Fi, encrypted to a one-time key, or as a file. Both phones show matching codes before anything is imported.
- Paper backup: a printable page with your key as a QR code and text, protected with a passphrase by default.
- Continue without unlocking: passphrase text and files work with the vault locked.
- "Also encrypt to" a backup key on every encrypt.

Changed
- Signed files are plain age files: the signature rides in an encrypted header stanza that covers who the file was encrypted to, so age -d returns your original bytes. Older signed files still verify.
- Saved recipients no longer count as trusted signers.

Fixed
- A duress password now makes the vault password-only, so Face ID can't skip it.
- The vault is kept out of iCloud and computer backups, and an app password is tied to this iPhone.
- Wrong password attempts slow down, with an optional erase after 10.
- The app switcher and screen recordings no longer show keys in sheets.
- Setup works on an iPhone with no passcode.
- Stricter file parsing, and leftover shared files are cleaned up.

Everything still runs on your device. No tracking, no ads.
